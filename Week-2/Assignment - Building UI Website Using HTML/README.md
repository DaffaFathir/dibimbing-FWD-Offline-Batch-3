# Movie Streaming Website UI

A static movie-streaming website interface built as an HTML and CSS project. It includes a movie discovery page and a movie details page.

## Pages

- [Landing Page](<./Landing Page.html>) — featured movie, trending titles, genre browsing, and new releases.
- [Detail Page](<./Detail Page.html>) — Movie overview, trailers, cast, ratings, movie information, and recommendations.

## Getting Started

1. Download or clone this project and keep the `Image/` and `Picture/` folders alongside the HTML files.
2. Open `Landing Page.html` in a web browser.
3. Select a movie poster to open the detail page.

The pages use external resources for styling, icons, and fonts, so an internet connection is needed for them to load.

## Technology Stack

- **HTML5** for page structure and content.
- **CSS3** for responsive landing-page styling.
- **Tailwind CSS 4 Play CDN** for the detail-page layout and utilities.
- **Font Awesome 6.7.2** for interface icons.
- **Google Fonts (Bebas Neue)** for display typography on the detail page.

## Notes

This is a front-end UI prototype. Search, subscription, rating, watchlist, and playback controls are visual elements and are not connected to a backend.
